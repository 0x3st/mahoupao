# 马后炮 / Mahoupao

中文 · [English](README.en.md)

一个每日自动更新的 ETF 定投账本：拉取 Tushare 真实行情，核算「每日收市固定投入」的收益率，并把行情快照（CSV）与投入/市值、账户收益率曲线图（SVG）发布到本仓库。网站展示同一份公开数据，不维护另一套回测。

**[打开指数网站 ↗](https://mahoupao-index.leiwu3.workers.dev)** · 指数读数与涨跌方向、交互历史曲线、组合账本和指标直觉，支持手机浏览。网站直接读取仓库日更数据；开发和部署说明见 [`website/README.md`](website/README.md)。

## 指标直觉 / Intuition

### 为什么叫「马后炮」？

看一段已经发生的行情，人很容易说：“要是当时买了就好了。”但挑中最低点买入，是事后的视角。马后炮换了一个不需要挑买点的问题：

> **如果从约定的那一天起，每个交易日都投入同样的钱，不猜涨跌，也不卖出，到今天这本账会怎样？**

它是一位假想的、严格执行规则的定投者的账本，不是对实际投资者平均表现的估计，也不是“最佳买点”的回测。

### 从市场价格，换到账户成本的视角

市场价格告诉我们“现在一份值多少钱”；这个指数告诉我们“现在的价格，相对这本定投账本积累的平均成本，高了还是低了多少”。

每天投入相同金额，价格低时买到的份额多，价格高时买到的份额少。因此，同样的当前价格，如果之前走过的路径不同，积累的份额和平均成本也可能不同，指数就会不同。它保留的是**从固定起点以来的定投成本记忆**，不是仅看今天价格的一张快照。

对单只 ETF，设第 `i` 个交易日的收盘价为 `P_i`，每天投入 `a` 元，共投入 `n` 次：

```text
持有份额 Q = Σ(a / P_i)
累计投入 I = n × a
当前市值 V = P_n × Q
平均每份成本 C = I / Q = n / Σ(1 / P_i)
马后炮指数 M = 100 × (V / I − 1) = 100 × (P_n / C − 1)
```

这里的平均成本是历史收盘价的**调和平均数**，不是价格的算术平均数。在当前允许小数份额、忽略交易费用等因素的模型中，每日投入金额 `a` 会约掉：每天投 10 元还是 100 元，改变的是账户规模，不是指数读数。

### 指数与 badge 分别怎么看？

指数直接取累计收益率的百分数值，去掉 `%`，以 **0 为回本线**，不是从 100 或 1000 起算的传统价格指数：

| 指数 | 账本含义 |
|---|---|
| `20` | 累计收益率为 20%，累计投入的每 100 元目前值 120 元 |
| `0` | 当前市值等于累计投入 |
| `−10` | 累计收益率为 −10%，累计投入的每 100 元目前值 90 元 |

**badge 的数值看累计盈亏，颜色看较上一交易日的涨跌：**

- 指数从 `20` 降到 `19`：badge 为绿色 `+19.00`。数值对应累计收益率 19%，绿色表示今天下降，账户仍在盈利。
- 指数从 `−10` 升到 `−9`：badge 为红色 `−9.00`。数值对应累计收益率 −9%，红色表示今天上升，账户仍在亏损。
- 指数不变或没有上一条记录：仍显示当前指数，颜色为灰色。

**数字不是两天之差，也不是 ETF 当日收益率；正负号表示累计盈亏，红绿表示日涨跌方向。** 所以正数可以是绿色，负数也可以是红色。图表和 CSV 中标为收益率的字段仍保留百分比口径。

还有一个容易忽略的细节：当天新投入的钱会增加本金，但买入当刻不产生盈亏。因此，即使价格不变，新投入也会把已有的累计收益率向零拉近；指数的变化（以及 badge 的颜色）同时反映价格变动和新增投入对账本的影响，不能直接当作当天赚亏了多少钱。

### 它能回答什么，不能回答什么？

它适合回顾同一套定投规则在不同资产上的账户体验：投入了多少、现在值多少、相对积累成本处于盈利还是亏损状态。组合读数按各账户市值之和除以投入之和计算；等额投入不意味着持仓市值始终等权，也不意味着定期再平衡。

但它不是年化收益率，不是估值高低的判定，也不代表真实投资者的平均持仓或情绪。**指数高不等于该卖，指数低不等于该买**；预测能力需要另外验证。起点、投入规则和价格路径都会影响读数，比较时必须保持口径一致。

这仍是一个简化的历史模拟：当前使用 ETF 收盘价，未计入手续费、现金分红或拆并份额等调整，也不是基金净值或底层指数的完整总回报。名字里的“马后炮”，提醒的正是这条边界：**描述已经发生的结果，不把事后解释包装成事前预测。**

## 回测口径

- 默认起点：`2014-01-15`，三只 ETF 的共同历史起点
- 每个标的使用自己的交易日历；非交易日不结算
- 每个交易日收市后按收盘价完成一次结算和估值
- 沪深300：`510300.SH`，华泰柏瑞沪深300ETF
- 标普500：`513500.SH`，博时标普500ETF(QDII)
- 黄金：`518880.SH`，华安易富黄金ETF

这版按固定金额允许买入小数份额，适合观察“每天投入100元”的资金曲线；真实场内交易通常还要考虑100份整数手、手续费、分红和申赎/折溢价。

## GitHub Actions 每日更新

仓库自带 `.github/workflows/daily-update.yml`，每天北京时间 20:30 左右自动运行：

1. 增量拉取 Tushare 新行情
2. 重新核算每日收益率
3. 更新 `data/export/` 下的 CSV 与 SVG 并提交

首次使用只需两步：

1. 在仓库 `Settings → Secrets and variables → Actions` 添加 `TUSHARE_TOKEN`
2. （可选）手动触发一次：`Actions → Daily update → Run workflow`

周末/节假日无新数据时，workflow 会自动跳过提交。

## 本地运行

```bash
cp .env.example .env
# 编辑 .env，填入你的 Tushare Pro Token
python3 sync_and_report.py
```

脚本会增量拉取新行情，并重新生成 `data/export/` 下的 CSV 与 SVG。
